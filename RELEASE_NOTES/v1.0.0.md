# v1.0.0

首个公开版本：一条斜杠命令把 DeepSeek Harness 的会话日志导出为 Markdown。

## 安装

```bash
dsh plugin --profile web add github:ErickYu-code/dsh-plugin-export-md#v1.0.0
```

装完确认 `~/.dsh/profiles/web/package.json` 的 `dsh.profile.bundles` 里出现
`dsh-plugin-export-md`；若斜杠菜单还没出现 `/export-md`，重启一次 DSH 服务。

## 功能

在任意会话输入框敲 `/export-md`，当前会话即渲染成一份 Markdown 文件，
默认写入 `~/.dsh/exports/`。命令直接读会话日志，**不产生模型消息、不消耗 token**。

```
/export-md                            默认级别（normal）导出
/export-md --brief                    只要对话正文
/export-md --full                     含系统提示词与注入上下文
/export-md --tools --no-tool-output   保留工具名，去掉工具输出
/export-md --tool-chars 0 --full      工具输出完整保留
/export-md --help                     全部选项
```

- 三个预设（`brief` / `normal` / `full`）+ 11 个可叠加开关，后写的覆盖先写的
- 正文、思考过程、工具调用、工具结果、注入上下文、系统提示词、token 用量可分别取舍
- 单条工具结果有独立字符预算（`--tool-chars`），超长内容保留头尾并标注省略量
- 代码围栏按内容自适应加长，导出内容自带 ``` 也不会破坏文档结构
- 跳过上下文压缩产生的改写型 surface 事件，只保留用户实际看到的对话
- 注入的上下文单独分组，轮次只数人的提问
- 支持 `--out` 指定任意路径，文件名带时间戳与标题，同名自动加后缀

## 实测体量

一次 140 步、172 次工具调用的真实会话：

| 级别 | 大小 |
| --- | ---: |
| `--brief` | 7.5 KB |
| `--normal` | 673 KB |
| `--full` | 750 KB |

## 兼容性与依赖

- DeepSeek Harness `>= 0.1.5-rc.1`（在 `0.1.5-rc.2` 上开发与验证）
- Node.js `>= 20`，需要 pnpm（`dsh plugin` 的转发目标）
- **零运行时依赖**，无构建步骤；从 git 安装不会触发 pnpm 的 `allowBuilds` 拦截

## 验证

`npm test` —— 24 项自检覆盖命令语法、渲染器、落盘与插件端到端流程，
另有一次真实会话日志（796 事件 / 172 次工具调用）的三种级别输出验证。

## 已知限制

- 只导出当前会话，暂不支持指定历史会话
- 图片/文件附件只记录引用信息，不嵌入二进制内容
- 导出目录在工作区之外，写文件不经过 DSH 沙箱
